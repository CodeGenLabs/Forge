# CONSTITUTION.md — 16のエンジニアリング憲法

Forgeを統治する16の絶対原則:

1. **カーネルのLLM呼び出しゼロ:** 完全な決定論的再現性を保証。
2. **終了コードによる統治:** 人間の対話ではなく、CLIのexit codeでゲートを制御。
3. **Gitが唯一の真実:** 外部データベースやキャッシュに依存しない。
4. **DAG主導の成果物管理:** すべてのフェーズは有向非巡回グラフのノードである。
5. **ASTによるアンカー固定:** 壊れやすい行番号ではなく構文木に知識を固定。
6. **機械的ドリフト検出:** 知識の陳腐化を数式とハッシュで算出。
7. **実装前の仕様定義:** コードを書く前に要件デルタを確定。
8. **厳格なTDDの強制:** Red-Green-Refactorサイクルを厳守。
9. **クレーム接触の完全説明義務:** 変更差分が触れた知識は必ず釈明する。
10. **一方向ラチェット原則:** 複雑度の高いトラックへの昇格のみ許可。
11. **主張前の検証原則:** コマンド実行による客観的証拠なしに完了を主張しない。
12. **ホストエージェントの中立性:** 特定エージェント向けの専用構文を排除。
13. **決定論的派生層:** 派生ファイルは改行LFおよびキー順序ソートを徹底。
14. **クレーム破棄の厳格化:** 4つの正当な理由以外での破棄を禁止。
15. **コミット前フックの配備:** リポジトリ境界でドリフト混入を防御。
16. **バージョンピンニング:** カーネルとリポジトリ設定の不整合を警告。
